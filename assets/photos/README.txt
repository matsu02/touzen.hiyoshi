写真をこのフォルダーに置き、assets/site-config.js の photos で指定してください。

推奨ファイル名:
hero.jpg        冒頭の稽古風景
solo.jpg        独り稽古
pair.jpg        対人稽古
instructor.jpg  主宰者

例:
hero: { src: 'assets/photos/hero.jpg', alt: '実際の写真の説明', position: '50% 50%' }

src を空文字のままにすると、現在の写真用スペースが表示されます。
画像ファイルのないパスを入れる必要はありません。
写真を入れると「写真準備中」の表示は自動的に消えます。
