# 刀禅日吉同好会

刀禅日吉同好会の活動を紹介するWebサイトのリポジトリです。

刀禅日吉同好会の活動と参加方法を紹介するWebサイトです。2017年から横浜市の日吉・綱島を中心に、刀禅と揺腕法の稽古を続けています。

身体を動かして確かめることと、動きの背後にある理を学ぶことを大切にしています。立つ・歩く・腕を振るといった基本から、独り稽古と対人稽古を通して、身体のつながりと働きを探っていきます。

Webサイトには、次の内容を掲載しています。

- 刀禅と揺腕法の紹介・よくある質問
- 稽古の日程・会場・参加案内
- 日吉同好会での稽古の特徴
- 主宰者の紹介
- 日々の稽古を記録した稽古日誌
- 参加申込み・お問い合わせの案内

HTML・CSS・JavaScriptで構成し、パソコンとスマートフォンでの閲覧に対応しています。

## 共有サムネイルの設定

`assets/site-config.js` の `thumbnail` で、リンクを共有したときの画像を指定します。初期値は `assets/photos/hero.jpg` です。

```js
thumbnail: {
  src: 'assets/photos/hero.jpg',
  alt: '日吉同好会のイメージ'
},
```

画像を `assets/photos/` に置いて `src` を変更し、次のコマンドを実行してください。公開済み画像のHTTP(S) URLも指定できます。

```sh
node scripts/update-thumbnail.mjs
```

設定ファイルと、更新されたHTML・テンプレートを一緒にコミット・公開してください。共有先が読み取れるよう、OGP・Twitter Cardの画像指定をHTMLに直接書き込みます。トップページ、日誌、その他の公開ページで共通の画像を使い、日誌を再生成しても設定が維持されます。公開先URLが変わる場合は `siteUrl` も変更してください。

## アナウンスの設定

`assets/site-config.js` の `announcements` に、表示する最終日と本文の組を追加します。複数ある場合は、`[]` の中にカンマで区切って並べます。

```js
announcements: [
  {
    date: '2026-10-06',
    text: '10月6日の稽古は綱島地区センターで行います。'
  },
  {
    date: '2026-10-13',
    text: '10月13日は木刀をご持参ください。'
  }
],
```

「稽古の日程・会場・参加費」の見出しの下に、有効な項目がすべて登録順で、それぞれ「アナウンス：本文」の形で表示されます。同じ日付の項目もすべて表示します。日付は表示終了日で、指定するとすぐに表示され、日本時間でその日が終わるまで有効です。ページを開いたままでも、期限を過ぎた項目だけが自動で消えます。

日付または本文が空欄、日付が無効、あるいは期限切れの項目は表示しません。表示する項目が一つもない場合は、余白も含めて欄ごと非表示になり、カレンダーが続きます。すべての掲載を取り下げるときは `announcements: []` にしてください。本文は通常の文字列として表示され、改行には `\n` が使えます。

## 日程確認アプリ（PWA）

サイトをホーム画面に追加すると、「刀禅日吉」のアイコンから `index.html#schedule` を開けます。稽古予定・次の稽古・アナウンスは、通常のサイトと同じデータを表示します。

- 上部メニューの「日程確認アプリ」から、追加案内の専用ページ `app.html` を開きます。
- ブラウザのインストール画面を利用できる場合は、「アプリを追加する」ボタンを表示します。ボタンを押すとブラウザの追加画面が開きます。
- 緑色の案内枠の右上に、稽古日程ページを開く共通のQRコードを一つ表示します。追加画面を利用できない場合は、端末に合う手順を表示します。iPhone・iPad／Androidの各項目には、案内文と稽古日程URL `https://matsu02.github.io/touzen.hiyoshi/index.html#schedule` を掲載します。そのURLまたは右上のQRコードから稽古日程のページを開き、ホーム画面に追加します。
- iPhone・iPad：稽古日程のページをSafariで開き、「共有」→「ホーム画面に追加」→「追加」。表示される場合は「ウェブアプリとして開く」をオンにします。
- Android：稽古日程のページをChromeで開き、メニューから「インストールしてショートカットを作成」→「インストール」、または「ホーム画面に追加」を選びます。

表示方法は自動で切り替わります。インストールを取り消した場合や追加画面を開けなかった場合も、手動の追加手順へ切り替えます。手動で追加する際の対象は「稽古日程のページ」と明記しています。QRコードの読み取り後、最後の追加操作は利用者が行います。表示するQRコードは既存の `assets/qr/hiyoshi-schedule-iphone.png` です。追加案内へ直接案内する場合は `https://matsu02.github.io/touzen.hiyoshi/app.html` を共有してください。アプリ名は「刀禅日吉 日程確認アプリ」、ホーム画面の短い表示名は「刀禅日吉」です。

PWA対応には `app.html`、`manifest.webmanifest`、`sw.js`、`assets/pwa.js`、`assets/pwa.css`、`assets/icons/`・`assets/qr/` と、変更した `index.html`・`assets/style.css`・`assets/calendar.js` を一緒に公開してください。日誌のヘッダーは `templates/journal.html` から再生成し、生成物も一緒に公開します。GitHub Pagesのリポジトリ配下でも動くよう、パスは相対指定にしています。ホーム画面への追加やオフライン用の保存は、HTTPSで公開したサイトまたはlocalhostで確認します。

通信できるときはページや設定をネットワークから取得し、通信できないときは保存済みの画面を使用します。`data/calendar.json` はService Workerから保存データを返さず、通信失敗時は従来どおり `assets/calendar-data.js` の予定を使い、カレンダーに保存済みデータであることを表示します。初回アクセス前のオフライン利用や、写真・日誌全体のオフライン閲覧は対象にしていません。

アプリに戻った際は日時と予定データを再確認します。新しく公開されたアナウンス本文は、ページを再読み込みすると反映されます。Googleカレンダーからの取り込み方法は従来と同じです。予定を変更したら `node scripts/update-calendar.mjs` を実行し、生成された `data/calendar.json` と `assets/calendar-data.js` も公開してください。PWA対応によって定期取り込みが追加されるわけではありません。

追加案内とオフライン処理の検証は、`node --test scripts/test-pwa-install.mjs scripts/test-pwa-worker.mjs` で実行できます。

## 稽古日誌の検証

`python3 scripts/check-journals.py` で、本文・記事数・リンク・本文の照合値を確認できます。

編集済み本文の `editedBodySha256` は、`blocks` の段落と箇条書きの各項目を掲載順に連結し、半角・全角スペースや改行などの空白を除いた文字列をUTF-8でSHA-256に変換した値です。本文を編集した際は、この方法で確認値を更新します。`source.bodySha256` は取り込み時の原資料の記録として保持します。
